# hydrogeo

Draws Piper (Piper-Hill) diagrams of water analyses for major ions.

Compatibility updates by Renova.

Version 0.6.1.9001: Removed the DESCRIPTION Date field and added Authors@R with aut and cre roles.

## Install

```r
install.packages("remotes")
remotes::install_github("renova-r/hydrogeo@renova-0.6.1.9001")
```
